# M5Stack Clock - 多機能時計アプリ

M5Stack用の多機能時計アプリケーションです。時計表示、ポモドーロタイマー、カスタムタイマーの3つのモードを備えています。

## 機能

### 🕐 時計モード (CLOCK)
- **現在時刻表示**: NTPサーバーから取得した正確な時刻を大きく表示
- **日付・曜日表示**: 年月日と曜日を表示
- **アラーム機能**: 指定時刻にアラーム音を鳴らします
  - アラームのON/OFF切り替え
  - 時刻設定（時・分）

### 🍅 ポモドーロモード (POMODORO)
- **作業・休憩サイクル**: 集中作業と休憩を自動で切り替え
- **サイクルパターン**:
  - 作業 15分 → 休憩 5分
  - 作業 30分 → 休憩 5分
  - 作業 45分 → 休憩 5分
  - 作業 60分 → 休憩 5分
- **プログレスバー**: 現在の進行状況を視覚的に表示
- **自動通知**: フェーズ終了時に音でお知らせ

### ⏱️ タイマーモード (TIMER)
- **カスタムタイマー**: 任意の時間（分・秒）を設定可能
- **カウントダウン表示**: 残り時間を大きく表示
- **タイムアップ通知**: タイマー終了時に音と画面点滅でお知らせ
- **編集モード**: 時間設定を簡単に変更可能

## 必要なもの

### ハードウェア
- M5Stack（M5Stack Core、Core2、CoreS3など）
- Wi-Fiアクセスポイント（時刻同期用）

## セットアップ

### 1. Arduino IDEの準備

1. Arduino IDEを起動
2. **ファイル > 環境設定** を開く
3. **追加のボードマネージャのURL** に以下を追加:
   ```
   https://m5stack.oss-cn-shenzhen.aliyuncs.com/resource/arduino/package_m5stack_index.json
   ```
4. **ツール > ボード > ボードマネージャ** を開く
5. 「M5Stack」を検索してインストール

### 2. 必要なライブラリのインストール

**スケッチ > ライブラリをインクルード > ライブラリを管理** から以下をインストール:
- **M5Unified** (by M5Stack)

### 3. Wi-Fi認証情報の設定

**重要**: Gitにパスワードを含めないため、以下の手順で設定します。

1. `credentials.template.h` を `credentials.h` にコピー:
   ```powershell
   # PowerShellの場合
   Copy-Item credentials.template.h credentials.h
   ```

2. `credentials.h` を開き、実際のWi-Fi情報を入力:
   ```cpp
   const char *WIFI_SSID = "your_actual_wifi_ssid";
   const char *WIFI_PASS = "your_actual_wifi_password";
   ```

3. ファイルを保存

**注意**: `credentials.h` は`.gitignore`に含まれているため、Gitにはアップロードされません。

### 4. M5Stackへのアップロード

1. M5StackをUSBケーブルでPCに接続
2. **ツール > ボード** から使用するM5Stackを選択
   - 例: M5Stack-Core2、M5Stack-CoreS3 など
3. **ツール > シリアルポート** から適切なポートを選択
4. **スケッチ > マイコンボードに書き込む** をクリック

## 使い方

### ボタン操作

#### 全モード共通
- **ボタンA**: モード切り替え (CLOCK → POMODORO → TIMER → CLOCK...)

#### 時計モード
- **ボタンB**: アラームのON/OFF切り替え
- **ボタンC**: アラーム時刻設定モードに入る/終了
- **設定モード中**:
  - **ボタンA**: 時間（時）を増やす（長押しで連続変更）
  - **ボタンB**: 分を増やす（長押しで連続変更）
  - **ボタンC**: 設定完了

#### ポモドーロモード
- **ボタンB**: タイマーの開始/一時停止
- **ボタンC**: リセット（最初のサイクルに戻る）

#### タイマーモード
- **ボタンB**: タイマーの開始/一時停止
- **ボタンB長押し**: タイマーをリセット（設定時間に戻す）
- **ボタンC**: 時間設定モードに入る/終了
- **設定モード中**:
  - **ボタンA**: 分を増やす（長押しで連続変更）
  - **ボタンB**: 秒を増やす（長押しで連続変更）
  - **ボタンC**: 設定完了

### 画面表示

- **ヘッダー**: 現在のモードと状態を表示
- **メイン表示**: 大きな文字で時刻や残り時間を表示
- **フッター**: ボタンの機能を表示
- **ボーダーハイライト**: 重要な通知時に画面外周が色付き

## カスタマイズ

`Clock.ino` の以下の部分を変更することで、動作をカスタマイズできます:

### NTPサーバー
```cpp
const char *NTP_SERVER = "ntp.nict.jp";  // 別のNTPサーバーに変更可能
```

### タイムゾーン
```cpp
const long GMT_OFFSET_SEC = 9 * 3600;  // 日本時間(JST)の場合は9時間
```

### ポモドーロサイクル
```cpp
const PomoPhase POMO_CYCLE[] = {
    {15, true},   // 作業15分
    {5, false},   // 休憩5分
    // ... 自由に変更可能
};
```

### カラーパレット
```cpp
#define C_BG 0x0000      // 背景色
#define C_ACCENT 0x07FF  // アクセント色
// ... など
```

## トラブルシューティング

### Wi-Fiに接続できない
- `credentials.h` のSSIDとパスワードが正しいか確認
- Wi-Fiルーターの2.4GHz帯が有効か確認（5GHz非対応）
- M5Stackを再起動してみる

### 時刻がずれる
- Wi-Fi接続を確認
- NTPサーバーが応答しているか確認
- タイムゾーン設定（GMT_OFFSET_SEC）を確認

### 画面が表示されない
- M5Stackのモデルとボード設定が一致しているか確認
- USBケーブルが給電に対応しているか確認

### ライブラリエラー
- M5Unifiedライブラリが最新版か確認
- Arduino IDEを再起動してみる
